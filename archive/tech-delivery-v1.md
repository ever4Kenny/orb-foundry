## 已实现

### Day1：物理底盘
- 竖屏 9:16 Canvas 2D 盘面（360×640）
- 固定 peg 布局：8 行交错排列，3 种类型（普通灰/奖励金/危险红）
- 2D 重力（500 px/s²）+ 球发射 + 圆形碰撞 + 反弹
- 3 个底部槽位：左（弹性+10%）、中（+10 分）、右（+1 球）
- 拖拽瞄准发射（鼠标 + 触屏）
- 实时得分显示

### Day2：球逻辑
- 4 种球：铁（穿透）、水晶（高弹）、磁（吸附奖励 peg）、玻璃（第 6 次碰撞分裂）
- 球袋系统：初始 6 颗 → 每轮抽 3 选 1 → 不回收 → 袋空补 2 铁球
- 轮次发球数限制：4/5/6
- 球物理参数差异：重量 0.5~2.0、弹性 0.3~0.9

### Day3：三轮循环
- 3 轮连续游戏，目标分 80/120/160
- 第 1 轮后：球三选一（铁/水晶/玻璃）
- 第 2 轮后：盘面改造二选一
  - 金属镀层：盘面中部 +4 奖励 peg
  - 危险清除：移除所有危险 peg + 等量普通 peg
- 轮次通过/失败判定和结果展示

### Day4：Bug 修复
- ✅ 弹性加成错误应用到当前球 → 修复为下次发射应用
- ✅ 球卡住/无限弹跳 → 添加 lifetime 6s 超时 + 速度下限清除 + 水平振荡检测
- ✅ 同屏球数上限 10
- ✅ 「再来一局」按钮
- ✅ 球飞出盘面 → 墙壁反弹 + 速度上限

## 已知风险

| 风险 | 严重度 | 说明 |
|---|---|---|
| 高弹性球弹跳过久 | 中 | lifetime 6s + 多层检测已缓解，但极端情况下玩家可能等 6 秒 |
| peg 隧道效应 | 低 | 速度上限 800px/s + dt 上限 0.04s 保证了 60fps 下不穿透 |
| 磁球吸附强度 | 低 | 硬编码 150 px/s²，未经玩家主观验证 |
| 分数节奏 | 中 | pegs 碰撞给分固定，缺少 combo/连击反馈，可能显得单调 |
| GitHub Pages 加载慢 | 低 | 纯静态单文件 23KB，国内访问可能有延迟 |
| 移动端触屏精度 | 低 | 已支持 touch 事件，但未在真机上测试 |

## 技术取舍

- 选 Canvas 2D 而非 Cocos Creator：避免 Editor 阻塞，单文件可部署，MV 验证够用
- 固定 peg 布局而非程序化生成：MVP 只需验证物理手感，不需要关卡多样性
- 硬编码效果而非通用触发器：数据结构预留 tags 字段，逻辑硬编码在当前回调中
- 零美术资产：纯几何形状 + 颜色区分，验证阶段不需要美术表现
